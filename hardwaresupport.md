# Hardware Support
poagyWorld is built into a single html file hosted on the poagyWorld website. While this means you do not have to download anything, it does mean you need a reasonably up-to-date web browser to be able to load the website and client correctly. Here is a reasonably up to date list of what operating systems will be able to load poagyWorld out of the box:

# Windows
Windows 10 and newer through Chrome or Firefox based browsers.
# macOS
macOS Ventura and newer through Chrome or Firefox,
macOS Catalina and newer through Firefox ESR.
# Linux
Anything that can run the latest version of Chromium or Firefox really, we're not testing them.
# Other OS
Any OS that can run modern versions of Chrome or Firefox should run poagyWorld fine.
